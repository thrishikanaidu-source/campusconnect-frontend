# CampusConnect: Frontend

React frontend for **CampusConnect**, a Student Attendance and Result Management Portal.
Backend repo: https://github.com/thrishikanaidu-source/campusconnect-backend

## Tech stack
- React (Vite)
- React Router
- Axios

## Features
- **Login page** with role-based redirect
- **Admin dashboard:** manage students, teachers, courses and create logins
- **Teacher dashboard:** mark attendance, enter marks
- **Student dashboard:** view own attendance percentage and marks, print result sheet

## How to run
1. Start the backend first (see the backend repo).
2. Install Node.js (version 20.19 or newer).
3. In this folder, run:
```
   npm install
   npm run dev
```
4. Open `http://localhost:5173`.
